# Individual kernel test harnesses

These tests isolate the current SYCL CKKS pipe graph one kernel at a time.
Each harness executable submits the kernel under test plus the minimum synthetic feeder/drainer kernels needed to drive its existing production pipes.

## Configure

Emulator/non-RTL runtime tests:

```bash
source /opt/intel/oneapi/setvars.sh --force
cmake -S . -B build-kernel-tests-emu \
  -DCMAKE_CXX_COMPILER=icpx \
  -DSYCL_CKKS_BUILD_KERNEL_TESTS=ON
```

Hardware/report targets:

```bash
source /opt/intel/oneapi/setvars.sh --force
cmake -S . -B build-kernel-tests-report \
  -DCMAKE_CXX_COMPILER=icpx \
  -DSYCL_CKKS_BUILD_KERNEL_TESTS=ON \
  -DSYCL_CKKS_FPGA_DEVICE=/home/uwb_student00/IA-840f/IOFS_BUILD_ROOT/oneapi-asp/ia840f/:ofs_ia840f
```

## Build and run emulator tests

The default emulator aggregate builds the runnable non-RTL tests:

```bash
cmake --build build-kernel-tests-emu --target ckks_kernel_tests_emu -j2
ctest --test-dir build-kernel-tests-emu --output-on-failure
```

Validated on Agilex7 with oneAPI 2024.1:

- `ckks_test_entry_emu`
- `ckks_test_exit_c0_p0_emu`, `p1`, `p2`
- `ckks_test_exit_ntt_a_p0_emu`, `p1`, `p2`
- `ckks_test_exit_ntt_b_p0_emu`, `p1`, `p2`
- `ckks_test_scale_reduce_p0_emu`, `p1`, `p2`
- `ckks_test_poly_mult_neg_add_p0_emu`, `p1`, `p2`

Expected CTest result:

```text
100% tests passed, 0 tests failed out of 16
```

## RTL-backed emulator targets

RTL-backed emulator targets are still generated individually and under:

```bash
cmake --build build-kernel-tests-emu --target ckks_kernel_tests_emu_rtl -j2
```

Targets:

- `ckks_test_ifft_emu`
- `ckks_test_ntt_a_p0_emu`, `p1`, `p2`
- `ckks_test_ntt_b_p0_emu`, `p1`, `p2`

Current Agilex7 limitation: the checked-in RTL archives were generated by HLS/compiler 25.3, but the workstation currently exposes oneAPI compiler 2024.1 through `/opt/intel/oneapi/setvars.sh`. The 2024.1 emulator device linker rejects the RTL archive payload while linking IFFT/NTT emulator executables. Hardware/report early-link targets do build.

Because of that tool/archive compatibility issue, RTL emulator CTest registration is opt-in:

```bash
cmake -S . -B build-kernel-tests-emu \
  -DCMAKE_CXX_COMPILER=icpx \
  -DSYCL_CKKS_BUILD_KERNEL_TESTS=ON \
  -DSYCL_CKKS_REGISTER_RTL_EMULATOR_CTESTS=ON
```

Use that only after regenerating RTL emulator archives with the active compiler or installing a compiler compatible with the existing archives.

## Build all report targets

This builds report/early-link targets for every individual kernel, including RTL-backed IFFT and NTT A/B:

```bash
cmake --build build-kernel-tests-report --target ckks_kernel_tests_report -j2
```

Validated on Agilex7 with oneAPI 2024.1 and IA-840F target path: the aggregate report target reaches `Built target ckks_kernel_tests_report`.

## Full hardware targets

Full hardware targets are generated but excluded from `ALL`. Build one explicitly, for example:

```bash
cmake --build build-kernel-tests-report --target ckks_test_scale_reduce_p0_fpga
```

Do not create or run an aggregate full-hardware build unless intentionally spending the hardware compile time.
